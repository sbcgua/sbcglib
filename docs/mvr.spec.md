# "MVR" package functionality

This document describes public functionality of the SBCGLIB `MVR` package.

## Public functionality

The code inside is a set of utilities to massively recreate maintenance views and to apply certain usability adjustments to them programmatically (like expand the resulting table width, field width, etc). Practical value is to avoid doing this manually is a known codebase.

To be described. Yet the example code can be observed in `zsbcglib_mvr_example` program. It defines example "configuration" the rest of includes. Those includes are "the reusable library", the program itself is an example.
